# OrangeSunshine

A Minecraft mod inspired by Psychedelicraft — adds drug effects, psychedelic shaders, crops,
items, and more.

---

## This Branch — 1.12.2 Backport

This is a **backported version** of OrangeSunshine for Minecraft **1.12.2**.

Active development is focused on newer versions. This branch will only receive updates if
there is enough community demand — if you want to see continued 1.12.2 support, let us know.

**Found a serious bug?** Contact us through our CurseForge page. Please include your
Minecraft/Forge version, a description of the issue, and any relevant crash logs.

---

## Features

- Psychedelic post-process shader effects (color rotation, bloom, kaleidoscope, recursion,
  wave distortion, camera tremble, and more)
- Growable drug crops (weed, coca, tobacco, peyote, san pedro, psilocybin mushrooms,
  ayahuasca vine, and more)
- Craftable drug items and consumables
- Custom processing blocks (Compound Extractor, Compound Compressor, Drying Table, Fridge)
- Psychedelic armor set
- ShmokeStackz villager trader

---

## Requirements

- Minecraft 1.12.2
- Forge 1.12.2-14.23.x
